UBER PROFIT PILOT — ANDROID INSTALLABLE WEB APP

This is a Progressive Web App (PWA), designed to install on Android from Chrome.

Files:
- index.html
- manifest.json
- sw.js

To install:
1. Put these files on a web host using HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the site in Chrome on Android.
3. Chrome menu -> Add to Home screen / Install app.

The app stores saved defaults locally on the phone and does not require an account.

Important:
- Earnings, insurance, taxes, depreciation and vehicle costs are estimates. Replace assumptions with your actual numbers.
- The app is a business calculator, not tax or financial advice.
